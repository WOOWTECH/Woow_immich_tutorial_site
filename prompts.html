用一句話，控制你的相簿

透過 Immich 的 REST API 或 MCP server，把下面這些自然語言提示詞交給 AI agent，讓它幫你整理相簿、找人臉、批次改 metadata、盤點備份。每一條都能複製，改成你家的說法就能用。

這本是什麼

Immich 有一整套 REST API（/api/albums、/api/search/metadata、/api/people 等）。把這些 API 包成 MCP 工具後，AI agent 就能用自然語言幫你操作相簿。這本是「你要對 agent 說的話」的範本庫。

前提：這些提示詞需要你的環境已接好 Immich MCP 或 API 存取權。第一次使用前，先確認 agent 能連到你的 Immich 伺服器。

怎麼用這些提示詞

複製 → 貼進你的 agent → 把「我家」這類佔位詞換成真實說法 → 送出。關鍵是講清楚「範圍」與「要做什麼」，避免 agent 誤動整庫。

安全習慣：任何「刪除、批次修改、分享」類的動作，都先要求 agent 回報「將影響 N 張照片」讓你確認，再執行。

相簿管理

建立相簿
幫我建立一本相簿叫做「2026 沖繩旅行」，然後把 2026 年 7 月拍攝、地點在沖繩的照片都加進去。
列出相簿
列出我所有的相簿，每本顯示名稱、照片數量、最近更新時間。
整理相簿
把相簿「雜項」裡拍攝時間在 2020 年以前、且不在任何其他相簿的照片，整理到一本新的「舊照片封存」相簿。
找重複
掃描整個圖庫，找出內容重複的照片，列出清單（不要刪除），等我確認後再處理。
相簿統計
統計我每本相簿的照片數與總容量，用表格呈現，並標出前 5 大的相簿。

人臉／人物

盤點未命名人物
列出所有還沒命名的人物，各附一張代表照片連結，讓我能快速命名。
合併人物
幫我合併人物：把所有疑似同一個人的「未命名人物」合併到已命名的「爸爸」名下。
找某人的照片
找出「媽媽」在 2023 到 2024 年間的所有照片，按時間排序，告訴我總共有幾張。
批次命名
把人物 ID 對應的未命名人物，依我給的名單批次命名（先列出對照表讓我確認）。
檢查辨識異常
找出「同一個人被拆成多個人物」的可疑狀況，列出可能該合併的人物群組。

時間／地點／語意搜尋

語意搜尋
幫我找「海邊的夕陽」相關的照片，依相關度排序，前 20 張即可。
時間範圍
找出 2025 年 12 月 24 日到 12 月 26 日之間拍攝的所有照片。
地點
找出所有 GPS 地點在「東京」附近的照片，用地點分組列出。
組合條件
找出「2024 年、有阿嬤、在廚房」的照片，這三個條件都要符合。
無地點照片
列出所有沒有 GPS 地點資訊的照片數量，並告訴我佔全庫比例。

匯入／匯出

匯出相簿
把相簿「婚禮」的所有原始檔打包，產生下載連結。
批次下載
把 2023 年整年的照片，依月份分資料夾整理成一個下載清單。
外部匯入
我有一個資料夾要匯入 Immich（路徑待我提供），幫我規畫批次匯入步驟，並確認重複偵測會開。
檢查完整性
檢查最近一次匯入的照片，是否有檔案損毀或 metadata 缺失，列出問題清單。

備份策略

備份盤點
盤點目前 Immich 的備份狀態：資料庫、照片原檔、設定檔各別有沒有備份機制，缺口在哪。
備份演練
寫一份 Immich 災難還原演練步驟：假設伺服器掛了，要怎麼從備份把照片與資料庫還原回來。
容量預估
依目前照片成長速度（我過去一年新增 X GB），預估多久會用到儲存上限。
清理建議
找出可以安全釋放空間的項目：重複照片、回收桶、轉碼暫存，各別估出可釋放容量。

共享連結

盤點分享
列出我所有「已分享」的相簿與連結，標出哪些是公開連結、哪些有期限、哪些快過期。
建立分享
幫相簿「家庭聚會 2026」建立一個分享連結，設 7 天有效、允許下載。
收回分享
把相簿「家庭聚會 2026」的所有分享連結停用，並確認不再可存取。
安全檢查
檢查有沒有「意外公開」的相簿：沒設期限、沒設密碼、內容含敏感資訊的，列出來。

metadata 批次編輯

補拍攝時間
找出沒有拍攝時間（EXIF 缺失）的照片，用檔名裡的日期補上拍攝時間（先給我看前 10 張的對照）。
補地點
把相簿「京都行」裡沒有 GPS 的照片，批次補上地點「京都」，先列出會影響幾張。
批次加標籤
把搜尋結果「貓」的所有照片加上自訂標籤「寵物」，先回報數量讓我確認。
修正時區
找出拍攝時間時區錯誤（例如出國沒調時區）的照片，依我給的時差批次修正。

排錯與維運

jobs 卡住
檢查 Immich 的背景 jobs 狀態，找出卡住或失敗的任務，並建議處理方式。
縮圖問題
有幾張照片縮圖一直模糊，找出原因（是否轉碼 jobs 沒跑完），並建議重跑哪些 job。
儲存告警
儲存空間低於 20% 時，幫我列出釋放空間的優先順序清單。
健康檢查
做一次 Immich 健康檢查：伺服器、資料庫、儲存、jobs，各項回報狀態與建議。

常見問題

提示詞要怎麼改才不會誤動整庫？
永遠加上「範圍」與「先回報、再執行」兩句話。例如「先列出會影響的照片數量，等我確認再執行」。
AI 找不到某個 API 端點？
Immich 版本不同，API 路徑會微調。先讓 agent 用 search 查 OpenAPI spec，再寫程式。
中文搜尋沒反應？
語意搜尋模型要支援中文。先用英文或簡單關鍵字測，確定模型能力再調整提示詞。
可以讓 agent 直接刪照片嗎？
可以，但強烈建議關掉「直接刪除」，改成「移到回收桶 + 回報」，多一層保護。
