Chapter 10

Admin settings

Get to know the admin panel: users, storage space and background jobs. By the end of this chapter, admins will be able to create accounts, reset passwords and check capacity, and will understand how background jobs such as AI analysis and backups run.

This chapter is for admins

Immich is a multi-user photo library, so someone has to create the accounts, keep an eye on capacity and watch the server's health. This chapter is a practical reference for admins (Admin); regular users can skip it, or just read it for the concepts.

Admin actions affect everyone: creating or disabling a user, changing storage and running jobs all affect the whole server. Confirm the scope before you act, and when in doubt, do not touch it.

What the admin panel manages

The admin entry point is "Administration" in the avatar menu in the top right. Inside, it is split into a few main areas:

AreaWhat it managesCommon actions
UsersCreating accounts, roles, disabling, password resetsCreate a new account, reset someone's password
StorageCapacity usage, storage locationCheck whether there is enough space, clean up
JobsSchedules for Thumbnails, AI analysis, Backup and so onCheck whether a job is stuck, trigger it manually
SettingsServer settings for AI, sharing, authentication and so onTurn face recognition and similar features on or off (Chapter 7)

Six steps to create a new user

  1. Open the admin panel

    Click the avatar in the top right → Administration, and confirm that you have admin permissions.

  2. Go to Users

    Open user management; you'll see the list of existing accounts.

  3. Create a user

    Click "Create user" or "Add user", and enter the person's email and display name.

  4. Set an initial password

    Give them a temporary password, and require them to change it after their first login (if the system supports it).

  5. Confirm the role

    Give regular users the User role; give Admin only when you are sure it is needed. The bigger the role, the bigger the impact of a mistake.

  6. Hand over the login details safely

    Give the person the URL, account and password through a private channel (do not paste them in a group chat), and remind them of the login precautions in Chapter 2.

Least privilege: give only User by default. An Admin can delete accounts and change server settings, so giving Admin to too many people increases the risk.

What background jobs are

After a photo is uploaded, much of the work is not finished "right away"; it goes into the background job queue, and the server works through the queue gradually in the background:

  • Thumbnails: generates preview images in various sizes so that browsing is faster.
  • AI analysis (Face recognition, Semantic search): the face recognition and semantic search from Chapter 7 are produced by these jobs.
  • Transcoding: converts videos into a format that can be played online.
  • Backup: database backups (if the server is set up for them).
Wait for jobs after a bulk upload: after you upload a few thousand photos at once, thumbnails and AI analysis take a while to run. The Jobs page shows the state of the queue; if it gets stuck, see Chapter 12.

Common admin pitfalls

  1. You cannot find the Administration entry

    Either your account is not an admin, or the entry is further down in the avatar menu. Check your role, or ask another admin to handle it.

  2. Resetting someone's password

    Find the user under Users, edit them and set a new password, then give the new password to them privately.

  3. Storage space is almost full

    Check the usage first, clean out the trash and duplicate files, and only then consider whether to expand storage.

  4. Jobs are stuck

    Refresh the Jobs page. If they stay stuck for a long time, the server may be short of resources or the queue may have a backlog; see Chapter 12.

Admin FAQ

Can regular users see the admin panel?
No. Only accounts with the Admin role have the Administration entry in the avatar menu.
Can I disable an account without deleting it?
Yes. Disable the account under Users; the person can no longer log in, but their data is kept. That is safer than deleting it outright.
Does deleting a user delete their photos?
Be very careful. Deleting a user may affect their data as well, so always double-check before you do it, to avoid wiping out someone else's memories by mistake.
Can jobs be run manually?
Yes. The Jobs page usually lets you trigger a type of job manually (such as regenerating thumbnails), which is useful when you are fixing a specific problem.
What should I watch out for when updating Immich?
Read the official release notes first (especially for a major version), confirm there are no breaking changes, and back up before you update. See Chapter 12.
