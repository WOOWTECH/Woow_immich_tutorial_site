Teach your AI agent to organize photos

A skill is the instruction manual that teaches an AI agent one specific craft. Install a photo management skill and your agent will organize, search and back up Immich for you, following best practice. This handbook collects hand-picked skills, popular collections and an install quick reference (2026-08 ecosystem survey).

What a skill is and why install one

Think of a skill as a "playbook (SOP) for the AI": a SKILL.md file that spells out "which task this is for, which steps to follow, which tools to use, and what to watch out for". Once the agent has read it, it can do one more thing, and it does it the same way every time instead of guessing.

For Immich, the common cases are: organizing albums in bulk, naming faces, duplicate detection, taking inventory of backups, and fixing metadata. Install the matching skill and you only have to say what you want; the agent follows the SOP.

How to install (the 3-minute version)

Prerequisite: your agent has to support skills (Pi Agent, Claude Code and the like). The install steps differ a little from agent to agent, but the idea is the same: drop the skill folder into the skills directory.
  1. Find the skill's GitHub repo and note the URL.
  2. In your agent's skill install panel, paste the repo URL or pick the directory.
  3. After installing, check that the skill shows up in the available list (or in the system prompt).

Compatibility notes

  • Version alignment: the Immich API changes from version to version (this guide covers v2.5.x). If a skill hard-codes API paths, it may need updating after you upgrade Immich.
  • Permissions: most operations need an admin's API key or that user's own API key; a skill is only useful if it can get a token.
  • AI models: semantic search skills depend on the ML model installed on the server. If the model is not set up, the skill has nothing to work with.

Safety rules

Never let a skill delete directly: every skill operation must go through "report first → you confirm → then execute", and anything deleted always goes to the trash first.
Keep tokens private: before you install a third-party skill, check whether it sends your API key or your photo paths anywhere outside. Do not install a skill whose origin you cannot trace.
Dry run first: for a batch operation, ask the skill for a "will affect N photos" preview first, and only let it run once the preview looks right.

SKILL.md quick reference

To write an Immich skill of your own, the core of it is a single SKILL.md file:

---
name: immich-album-organizer
description: Batch-organize Immich albums by time + place + people rules, with a dry-run mode
---
# Purpose
Sort photos into albums according to the user's rules.

## Steps
1. Read album and photo metadata first
2. Apply the sorting rules and produce a "preview list" (N photos affected)
3. Call the API only after the user confirms
4. Report the results and any exceptions

## Safety
- Never delete directly; always move to the trash
- Report the scope before any batch operation

For the full spec, see the skill documentation of the agent you use.

FAQ

How is a skill different from an app or an integration?
An app is a program with an interface, an integration wires two services together, and a skill is the manual that teaches the AI how to do something. Install it and the agent can do the work itself.
Can the wrong skill break my photo library?
It can. That is why the safety rules matter most: install only from sources you trust, always dry run first, and send deletions to the trash.
Can I write my own skill?
You can. Follow the SKILL.md skeleton above and spell out the Steps and Safety sections clearly.
Which skill is worth installing first?
"Duplicate detection + batch organizing" is the pair people use most; you feel the gain in space and tidiness right away.
