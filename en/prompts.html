Command your photo library in one sentence

Through the Immich REST API or an MCP server, hand the natural-language prompts below to an AI agent and let it organize albums, find faces, edit metadata in bulk and take inventory of your backups for you. Copy any of them, reword them to match your own household, and they are ready to use.

What this handbook is

Immich has a full REST API (/api/albums, /api/search/metadata, /api/people and so on). Wrap those endpoints as MCP tools and an AI agent can work on your photo library in natural language. This handbook is the template library for "what you say to the agent".

Prerequisite: these prompts need an environment that already has Immich MCP or API access set up. Before you use them for the first time, confirm the agent can reach your Immich server.

How to use these prompts

Copy → paste into your agent → replace placeholder words like "my home" with your own wording → send. What matters is being clear about the scope and the action, so the agent does not touch the whole library by mistake.

Safety habit: for any "delete, bulk edit, share" action, make the agent report "this will affect N photos" and wait for your confirmation before it runs.

Album management

Create an album
Create an album called "Okinawa trip 2026", then add every photo taken in July 2026 with a location in Okinawa. Answer in English.
List albums
List all of my albums, showing the name, the photo count and the last update time for each one. Answer in English.
Tidy up an album
Take the photos in the album "Misc" that were taken before 2020 and are not in any other album, and organize them into a new album called "Old photos archive". Answer in English.
Find duplicates
Scan the whole library and find the photos whose contents are duplicates. List them (do not delete anything) and wait for my confirmation before you do anything else. Answer in English.
Album statistics
Count the photos and the total size of each of my albums, present it as a table, and flag the 5 largest albums. Answer in English.

Faces and people

Take inventory of unnamed people
List every person who has not been named yet, each with a link to one representative photo, so I can name them quickly. Answer in English.
Merge people
Merge people for me: merge all the "unnamed people" who look like the same person under the already-named "Dad". Answer in English.
Find one person's photos
Find every photo of "Mom" taken between 2023 and 2024, sort them by time, and tell me how many there are in total. Answer in English.
Batch naming
Batch-name the unnamed people that match the person IDs, using the list I give you (show me the mapping table first so I can confirm). Answer in English.
Check for recognition problems
Find the suspicious cases where "one person has been split into several people", and list the groups of people that probably should be merged. Answer in English.

Time, place and semantic search

Semantic search
Find photos related to "sunset at the beach", sorted by relevance; the top 20 is enough. Answer in English.
Date range
Find every photo taken between December 24 and December 26, 2025. Answer in English.
Place
Find every photo whose GPS location is near "Tokyo", and list them grouped by place. Answer in English.
Combine filters
Find the photos that match "2024, with Grandma, in the kitchen". All three conditions have to be true. Answer in English.
Photos with no location
List how many photos have no GPS location data, and tell me what share of the whole library that is. Answer in English.

Import and export

Export an album
Package every original file in the album "Wedding" and produce a download link. Answer in English.
Bulk download
Take the photos from all of 2023 and organize them into one download list, with a folder per month. Answer in English.
External import
I have a folder to import into Immich (I will give you the path). Plan the batch import steps for me, and confirm that duplicate detection will be on. Answer in English.
Check integrity
Check the photos from the most recent import for corrupted files or missing metadata, and list the problems. Answer in English.

Backup strategy

Backup inventory
Take inventory of the current Immich backup status: whether the database, the original photo files and the config files each have a backup mechanism, and where the gaps are. Answer in English.
Backup drill
Write an Immich disaster recovery drill: assume the server is down, and describe how to restore the photos and the database from a backup. Answer in English.
Capacity forecast
Based on the current rate of photo growth (I added X GB over the past year), estimate how long it will be until I hit the storage limit. Answer in English.
Cleanup suggestions
Find the items where space can safely be freed: duplicate photos, the trash, transcoding temp files. Estimate how much each one would free. Answer in English.

Shared links

Take inventory of shares
List all of my "shared" albums and links, and flag which of them are public links, which have an expiry and which are about to expire. Answer in English.
Create a share
Create a shared link for the album "Family gathering 2026", valid for 7 days, with download allowed. Answer in English.

Disable every shared link on the album "Family gathering 2026", and confirm it is no longer accessible. Answer in English.

Batch metadata editing

Fill in capture times
Find the photos with no capture time (missing EXIF), and fill the capture time in from the date in the file name (show me the first 10 side by side first). Answer in English.
Fill in places
Batch-fill the place "Kyoto" onto the photos in the album "Kyoto trip" that have no GPS, and list how many photos this will affect first. Answer in English.
Batch tagging
Add the custom tag "pets" to every photo in the search results for "cat", and report the count first so I can confirm. Answer in English.

Troubleshooting and operations

Stuck jobs
Check the status of Immich's background jobs, find the ones that are stuck or failed, and suggest how to handle them. Answer in English.
Thumbnail problems
A few photos have thumbnails that stay blurry. Find the cause (whether the transcoding jobs have not finished), and suggest which jobs to re-run. Answer in English.
Storage alert
When storage space drops below 20%, list the priority order for freeing space. Answer in English.
Health check
Run an Immich health check: server, database, storage, jobs. Report the status and a recommendation for each. Answer in English.

FAQ

How do I edit a prompt so it does not touch the whole library by accident?
Always add two sentences: the scope, and "report first, then execute". For example: "list how many photos this will affect and wait for my confirmation before you run it".
The agent cannot find an API endpoint?
API paths shift slightly between Immich versions. Have the agent look up the OpenAPI spec with search first, then write the code.
Search in a language other than English returns nothing?
The semantic search model has to support that language. Test with English or simple keywords first, confirm what the model can do, then adjust the prompt.
Can I let the agent delete photos directly?
You can, but we strongly recommend turning off direct deletion and using "move to the trash + report" instead, for one more layer of protection.
