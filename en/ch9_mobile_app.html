Chapter 9

Mobile app backup

Install the Immich mobile app on your phone, connect it to your server, and let the photos on your phone back up to Immich automatically. By the end of this chapter, the memories on your phone will be kept at home automatically and continuously, instead of living only on one phone that could break at any moment.

Your phone holds the most photos, and loses them most easily

Most photos live on a phone these days. A phone can be lost, broken or replaced, and the photos go with it. Install the app and turn on automatic backup, and the photos on your phone keep syncing to the Immich server: one more layer of protection.

Chapter task: install the app, log in to the server, and turn on automatic backup. Installing the app only affects your own phone; it does not touch the server.

Automatic backup vs manual upload

MethodApproachBest for
Automatic backupThe app keeps sending new photos to the server in the backgroundEveryday use: set it up and forget about it
Manual uploadPick photos by hand in the app or on the web and upload themUploading old photos you missed, or controlling when the upload happens
Background backup has conditions: the phone's operating system (iOS / Android) limits what runs in the background, and the app needs the matching permissions before it can back up automatically. Grant the permissions when you first set it up, and it runs without trouble afterwards.

Six steps to set up phone backup

  1. Download the Immich app

    Search for "Immich" in the App Store (iOS) or Google Play (Android) and install it.

  2. Enter the server URL

    Open the app and enter the server URL https://woowtech-immich.woowtech.io. Make sure it is complete, including the https.

  3. Log in to your account

    Log in with the email and password from Chapter 2. The same account can be used on your phone and in the web app at the same time.

  4. Turn on automatic backup

    In the app's backup settings, turn on automatic backup and choose which albums to back up (for example "All photos").

  5. Grant the photo and notification permissions

    The system asks for permissions such as photo access and background refresh. Allow them all; the backup only runs properly with them.

  6. Confirm the backup has started

    Go back to the timeline in the web app and check that the photos from your phone are starting to appear. That means the backup is working.

The first backup takes a long time: if your phone already holds a large number of photos, the first full backup can run for a very long time and use a lot of data. We recommend connecting to Wi-Fi before you start, and keeping the app in the foreground for a while.

Backup settings worth adjusting

  • Back up only new photos: avoids uploading old photos again.
  • Back up only on Wi-Fi: saves mobile data.
  • Background backup: lets the app keep syncing in the background.
  • Exclude albums: for example the screenshots and downloads folders, so you do not back up noise.
Back up what matters first: for the first run, back up the essentials such as the camera roll, and think about the other albums once that has finished, so you do not push too much through at once.

Common app pitfalls

  1. Cannot connect to the server

    Check that the URL is complete (including https) and that your network is working. Open the same URL in a browser to test it; if the browser cannot open it either, the problem is the server or the network.

  2. Background backup does not run

    Check that all of the app's permissions (photos, background refresh, notifications) are on, and make Immich an exception in the phone's battery saver.

  3. Backup stops halfway

    Switch back to Wi-Fi, make sure the phone has battery, and bring the app to the foreground so it can continue. Large video files get stuck easily, so you can back up the photos first.

  4. Photos are backed up twice

    Check that duplicate detection is on. If you re-upload the same batch by hand, Immich usually skips the duplicates automatically.

App FAQ

Is the data in the app the same as on the web?
Yes. The app and the web app connect to the same server with the same account, so the photos are shared between them.
Does backup use a lot of mobile data?
Yes, especially the first full backup. We recommend setting "back up only on Wi-Fi", or running the first backup to completion while you are on Wi-Fi.
Does the backup start over when I switch phones?
Just log in with the same account: photos that are already backed up are not uploaded again, and the new photos on the new phone keep backing up.
If I delete a photo on my phone, is it deleted on the server too?
It depends on your backup settings. Be careful: check the settings before you delete photos on your phone, so you do not delete your only backup by mistake.
Can I back up videos?
Yes, but video files are large, so they back up more slowly and take up more space. Decide whether to include them in automatic backup based on what you need.
