讓 AI agent 會整理照片

Skill 是教 AI agent 一項專門手藝的「說明書」。裝上照片管理相關的 skill，你的 agent 就會照著最佳做法幫你整理、搜尋、備份 Immich。這本收錄精選 skill、熱門集合與安裝速查（2026-08 生態調查）。

Skill 是什麼，為什麼要裝

Skill 可以想成「給 AI 的 SOP 手冊」：一份 SKILL.md 檔寫明「遇到什麼任務、照什麼步驟、用什麼工具、注意什麼」。agent 讀到它，就多會一件事，而且做法穩定、不會每次憑空亂猜。

對 Immich 來說，常見的 skill 場景：批次整理相簿、人臉命名、重複偵測、備份盤點、metadata 修正。裝了對應 skill，這些事你只要下指令，agent 就會照 SOP 做。

怎麼裝（3 分鐘版）

前提：你的 agent 要支援 skill（例如 Pi Agent、Claude Code 等）。不同 agent 的裝法略異，但概念相同：把 skill 資料夾放進 skills 目錄即可。
  1. 找到 skill 的 GitHub repo，記下網址。
  2. 在你的 agent 的 skill 安裝面板，貼上 repo 網址或選取目錄。
  3. 安裝後，確認 skill 出現在可用清單（或系統提示裡）。

精選照片管理 skill（家庭視角）

以下依「家庭相簿管理」會遇到的真實需求，整理值得一找的 skill 類型。星數以 GitHub 現況為準（2026-08），安裝前務必確認 repo 仍在維護。

相簿批次整理

分類：整理 · 觸發 Immich REST API

照「時間＋地點＋人物」規則自動分類照片進相簿，附重複偵測與乾跑模式（先回報再動手）。

人臉命名工作流

分類：整理 · 觸發 /api/people

把未命名人物批次命名、合併疑似重複人物，並產出「待確認清單」給你核對。

metadata 修復

分類：整理 · EXIF／GPS

補拍攝時間、補地點、修時區，先產生對照表確認後才寫入。

備份與災難還原

分類：維運 · 資料庫＋檔案

盤點備份狀態、產出還原演練步驟、估算容量成長。

分享安全檢查

分類：安全 · 分享連結

掃描所有分享連結，標出無期限、無密碼、內容敏感的風險項目。

星數與名稱以 GitHub 現況為準：生態變化快，本頁列的「類型」是穩定需求，實際 repo 名稱與星數請安裝前重新查證。

熱門集合與工具（不只 skill）

除了 agent skill，Immich 生態還有這些常用的輔助工具與集合，值得一起認識：

工具／集合用途何時用
immich-app/immich官方主 repo（伺服器＋App）查文件、看更新、回報 issue
immich-cli命令列工具批次上傳、腳本化操作
immich-goGo 寫的上傳工具大量照片快速匯入
immich-power-tools社群進階工具集合批次整理、進階 metadata
Home Assistant 整合把 Immich 接進 HA自動化：偵測到新照片就通知等
Frigate（NVR）整合監視器影像＋相簿把監視畫面快照存進 Immich

相容性須知

  • 版本對齊：Immich API 隨版本變動（本教學為 v2.5.x），skill 若寫死 API 路徑，升級 Immich 後可能要跟著更新。
  • 權限：多數操作需要 admin 或該使用者的 API key；skill 要能拿到 token 才有用。
  • AI 模型：語意搜尋類 skill 依賴伺服器裝的 ML 模型，模型沒裝好，skill 也無從發揮。

安全守則

永不讓 skill 直接刪除：任何 skill 的操作都要走「先回報 → 你確認 → 再執行」，刪除一律先進回收桶。
token 不外流：裝第三方 skill 前，檢查它會不會把 API key、照片路徑傳到外部。來路不明的 skill 不要裝。
乾跑優先：批次操作先要求 skill 產出「將影響 N 張」的預覽，確認無誤才放行。

SKILL.md 規格速查

想自己寫一個 Immich skill，核心就是一份 SKILL.md：

---
name: immich-album-organizer
description: 依時間＋地點＋人物規則批次整理 Immich 相簿，附乾跑模式
---
# 用途
照使用者規則把照片分類進相簿。

## 步驟
1. 先讀取相簿與照片 metadata
2. 套用分類規則，產生「預覽清單」（影響 N 張）
3. 等使用者確認後才呼叫 API 執行
4. 回報結果與例外

## 安全
- 永不直接刪除，一律移回收桶
- 批次操作前必須先回報影響範圍

詳細規格請參考你使用的 agent 的 skill 文件。

常見問題

Skill 和 App／整合有什麼不同？
App 是「有介面的程式」，整合是「兩個服務串接」，Skill 是「教 AI 怎麼做」的說明書，裝了讓 agent 自己會操作。
裝錯 skill 會弄壞我的相簿嗎？
有可能。所以安全守則最重要：只裝可信來源、永遠先乾跑、刪除先進回收桶。
我能自己寫 skill 嗎？
能。照上面的 SKILL.md 骨架，把「步驟」和「安全」寫清楚即可。
哪個 skill 最值得先裝？
「重複偵測 + 批次整理」最常用，能立刻感受到空間與整理的效益。
